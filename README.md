# Mind-Sight-autism-detection-using-multimodel-
MindSight: Multi-modal deep learning system for early autism detection. Combines DistilBERT (text), EfficientNet (image), and VGG16+Bi-LSTM (video) via weighted ensemble with complete Explainable AI. Works with any input combination. Python, TensorFlow, PyTorch. First XAI-enabled missing-modality ensemble for ASD.
